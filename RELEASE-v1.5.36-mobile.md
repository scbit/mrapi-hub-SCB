# MRAPI Hub v1.5.36-mobile

Base: v1.5.35 (working messaging/audio/Dialogflow build).

## Mobile changes
- Mobile responsive layer across Hub home, Bandeja, CRM Pipeline, Contactos, Agenda, Recontacto, Mi Estado and Usuarios.
- iPhone safe-area support (`viewport-fit=cover`, top/bottom insets).
- Touch targets and 16px inputs to avoid iOS zoom.
- Bandeja: full-screen list/chat flow, compact KPI carousel, mobile-safe composer, horizontally scrollable action/tool rows, full-screen CRM side panel, bottom-sheet modals.
- CRM: compact filters, safe full-width drawer/modals, responsive cards and bulk controls.
- CRM tools: card-style mobile tables, one-column forms, bottom-sheet modals, scrollable module/tabs bars.
- Recontacto: single-column filters/forms and mobile campaign manager.
- Hub home: mobile bottom navigation and one-column module cards.
- No backend/API/Firestore/Dialogflow/Gateway behavior changed.
