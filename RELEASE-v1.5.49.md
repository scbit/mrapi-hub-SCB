# MRAPI Hub v1.5.49

## Mis Campañas en Mi Estado Comercial

- Se agrega **Mis Campañas** dentro de `/mi-estado`.
- Cada usuario administra sus propias campañas comerciales personales.
- Crear, editar y eliminar campañas con nombre y descripción.
- Agregar un trato desde cualquier bloque de Mi Estado con **+ Campaña**.
- Un mismo trato puede pertenecer a varias campañas.
- Abrir una campaña para ver sus tratos con etapa, vencimiento, calidad y owner actuales.
- Búsqueda rápida dentro de la campaña.
- Indicadores de total, vencidos y ganados.
- Acciones directas: abrir CRM, ir al HUB y quitar de campaña.
- Las campañas NO modifican pipeline, etapa ni owner del trato.
- Los usuarios solo pueden agregar tratos que ya tienen permiso de visualizar.

## Compatibilidad

Se mantiene la base funcional de v1.5.48, incluyendo Centro de Recontacto con Twilio + MRAPI Gateway/Meta Cloud API y el resto de las funciones existentes.
