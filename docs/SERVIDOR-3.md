# servidor-3

## Objetivo

Compactar el contexto publicitario en Bandeja para que el chat no quede visualmente chico cuando una conversación trae anuncio Meta/Facebook/Instagram con mucho texto.

## Cambio

- El bloque de publicidad queda acotado a una altura máxima.
- La imagen del anuncio se muestra más compacta.
- Texto y metadata del anuncio usan overflow interno.

## Riesgo de datos

Sin cambios de backend, Firestore, Twilio, webhooks ni escrituras.
