# MR API HUB v0.2

## Implementado
- `/inbox`: UI real de Bandeja.
- Login usando usuarios actuales de `bscrmscb` y token firmado local.
- Listado de conversaciones de `bsscb` con paginación por cursor.
- 50 conversaciones por página por defecto.
- Apertura de mensajes con límite de 60 por conversación.
- Hasta 3 IDs relacionados adicionales únicamente cuando el documento ya los conoce.
- Búsqueda histórica por teléfono mediante query selectiva `where(waFrom, in, ...)`.
- Búsqueda por nombre/empresa/texto limitada a la página ya cargada: 0 reads adicionales.
- HUMAN/BOT con 1 write y 0 reads adicionales.
- Marcar conversación como leída con 1 write.
- Contador visual de reads estimados de la sesión de UI.
- Favicon local: elimina el 404 de `/favicon.ico` al usar el icono SVG en las páginas.

## Regla de reads
No existe ningún `collection('conversations').get()` sin `limit`, ni búsqueda de 15.000 documentos.
