# MR API HUB v0.3

## Bandeja operativa

Esta versión agrega envío manual de WhatsApp sobre la Bandeja v0.2:

- texto desde conversaciones en modo HUMAN;
- adjuntos PDF/JPG/PNG/WEBP de hasta 15 MB;
- listado y envío de plantillas aprobadas de Twilio;
- persistencia de mensajes salientes en `bsscb`;
- actualización del resumen de conversación;
- callback de estado de Twilio sin búsquedas globales: el `conversationId` viaja en la URL y el callback escribe directamente en el documento del mensaje.

## Firestore / reads

Enviar un mensaje realiza una lectura de la conversación para validar número, línea y modo HUMAN. Luego hace escrituras, no relecturas masivas.

El callback de delivery no usa `collectionGroup().where(...)`; escribe directamente a:

`conversations/{conversationId}/messages/{MessageSid}`

Esto evita lecturas adicionales por cada estado `queued/sent/delivered/read`.

## Variables nuevas

- `TWILIO_ACCOUNT_SID`
- `TWILIO_AUTH_TOKEN`
- `TWILIO_WHATSAPP_FROM`
- `MRAPI_FILES_BUCKET=scb-whatsapp-media`
- `MRAPI_PUBLIC_BASE_URL=https://mrapi-hub-scb-604957912671.us-central1.run.app`

Los secretos de Twilio deben configurarse mediante Secret Manager en producción.

## Deliberadamente pendiente

No se porta todavía la recepción webhook de WhatsApp al nuevo Cloud Run. Mientras se prueba v0.3, el webhook entrante puede seguir apuntando a la Bandeja anterior, que continúa escribiendo en `bsscb`; MR API HUB verá esos mensajes porque comparte la misma base. Esto evita que dos Cloud Run procesen el mismo mensaje entrante.
