# MR API HUB v0.4

Primer port funcional del CRM actual al núcleo modular.

## Incluido
- `/crm` bajo el mismo Master Login que Bandeja.
- Pipeline de tratos real en `bscrmscb`.
- Filtros por etapa, owner y tipo usando queries Firestore.
- Paginación con cursor (50 por vez).
- Detalle de trato + contacto.
- Edición de etapa, tipo, calidad, valor, vencimiento y notas.
- Búsqueda dirigida por Deal/Contact ID o teléfono exacto.
- Permisos de visibilidad compatibles con admin/backoffice, team_leader y field_sales.
- Navegación común Bandeja / CRM / HUB.

## Política de reads
No existe fallback que haga `.collection(...).get()` masivo. Si falta un índice compuesto, la API devuelve un error claro para crear el índice en lugar de escanear miles de documentos.

La búsqueda global por nombre/empresa se deja para un índice materializado posterior; esta versión no sacrifica costo por comodidad.
