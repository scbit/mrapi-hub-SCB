# MR API HUB v0.5

## CRM product redesign

- Desktop Kanban with horizontal stage navigation and drag & drop.
- Mobile-first CRM: one stage at a time, vertical cards, full-screen detail drawer and bottom navigation.
- List view for dense operation and mobile use.
- Unified MR API HUB navigation: Bandeja / CRM / HUB.
- Deal detail drawer: title, stage, owner, type, quality, USD value, due date, notes and contact data.
- Note history restored with a hard limit of 30 entries.
- Quick links to WhatsApp and Bandeja.
- Session read estimate remains visible.
- Loaded-page indicators are computed in the browser and create 0 extra Firestore reads.

## Firestore rules kept

- No `collection.get()` fallback in interactive pipeline requests.
- Deal pages stay cursor-paginated.
- Drag & drop performs one permission read + one write for the moved deal.
- Opening detail performs one deal read + at most one contact read.
- Note history is opt-in and limited to 30; it is never loaded with every card.
- Summary cards are derived from already-loaded deals, with 0 additional reads.

## Still intentionally pending

The old SCB CRM contains specialized modules that will be ported as separate MR API HUB modules instead of being folded back into one giant CRM file: Agenda/Tareas, Vencimientos/Campaign jobs, KPI/Targets, Plan de Producción, Product Search, Knowledge Base, Importer and user administration.
