# MR API HUB v0.6

## CRM pipeline workspace

- Vistas guardadas por usuario en Firestore (`users/{uid}/crmViews`), cargadas una sola vez al iniciar CRM.
- Orden de etapas configurable por vista.
- Mostrar/ocultar etapas.
- Colapsar/expandir columnas.
- Pipeline ocupa el alto disponible de la ventana: el scrollbar horizontal queda visible sin bajar al final de la página.
- `Cargar 50 más` global desde la barra de filtros.
- `Cargar más de esta etapa` en cada columna, usando cursor por `createdAt + documentId`; no hay collection scan.
- Selección múltiple y movimiento masivo de etapa (máximo 100 por operación).
- Preferencias locales de UI para respuesta inmediata y vistas persistentes para reutilizar configuraciones.
- Móvil conserva vista por etapa, detalle full-screen y navegación inferior.

## Estrategia de reads

- Guardar/ordenar/colapsar una vista no lee deals.
- Abrir CRM agrega como máximo 30 reads de vistas guardadas, además de meta y primera página.
- Cargar más por etapa consulta solo esa etapa y solo la siguiente página.
- Bulk move lee únicamente los documentos seleccionados para validar permisos antes del batch write.
