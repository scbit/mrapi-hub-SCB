# MR API HUB v1.1

## Bandeja operativa
- Crear contacto desde una conversación sin vínculo.
- Crear trato y vincularlo automáticamente a la conversación.
- Si ya existe contacto pero no trato, botón Crear trato en el panel CRM.
- Filtros rápidos en memoria sobre las conversaciones ya cargadas: Todos, No leídos, Nuevos / sin asignar, Vinculados. Estos filtros no generan reads adicionales.
- Filtro de uno o varios owners (máximo 10 por query) contra Firestore, con validación de permisos en backend.
- Admin/backoffice: pueden elegir cualquier owner disponible.
- Team leader: solo owners visibles de su equipo.
- Vendedor: solo su owner permitido.
- No hay fallback a full scans. Si Firestore requiere índice para combinación owner + fecha, la API devuelve el error de índice en lugar de escanear la colección.
- Marcar leído ahora sincroniza hasUnread=false y unreadCount=0.
