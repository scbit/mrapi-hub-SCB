# MR API HUB v1.2

## HUB / Bandeja
- Crear trato muestra todas las etapas reales definidas por CRM.
- Buscador de etapa dentro del modal para filtrar rápidamente.
- Owner del trato editable desde el resumen CRM lateral.
- Owner del contacto editable de forma independiente desde el resumen CRM lateral.
- Selectores de owner usan únicamente owners permitidos por `/api/crm/meta` según el usuario autenticado.
- Validación de permisos también en backend; el frontend no es autoridad.

## Firestore
- Cambiar owner de trato: 1 read directo + 1 write.
- Cambiar owner de contacto: 1 read directo + 1 write.
- La lista de stages viene del metadata CRM ya cargado; no agrega scans.
