# MR API HUB v1.3

Primer bloque de módulos recuperados del CRM completo legacy.

## Portado
- Contactos: crear, editar, estado, owner, tratos vinculados y cargar 25 más.
- Agenda Comercial: tareas + vencimientos, rangos, owner, stage, estado y tipo.
- Vencimientos: vista específica del mismo motor de agenda.
- Crear tareas y marcarlas hechas/reprogramarlas.
- Ir al trato y al HUB desde Agenda.

## Estrategia de reads
- Contactos: páginas de 25, máximo 50 por request.
- Enriquecimiento de tratos solo para contactos de la página.
- Agenda: queries por `taskDate` / `dueDate`, límite máximo 200.
- Filtros de permisos en backend.
- Si Firestore requiere índice, devuelve error en vez de hacer fallback masivo.
