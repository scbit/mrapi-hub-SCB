# MR API HUB v1.4.4

Mi Estado vuelve a la estructura operativa validada del CRM legacy, manteniendo el diseño MR API HUB.

## Mi Estado
- Todos los bloques visibles en una misma pantalla: Nuevos Prospectos, Seguimiento, Marca personal, Esperando PI, Para cotizar, Cotizado para enviar y Horno.
- Cada bloque tiene tabla propia y scroll interno en desktop.
- Refrescar independiente por bloque.
- Ver 25 más por bloque.
- Edición inline de vencimiento, etapa, calidad y nota rápida.
- Guardar por trato.
- Abrir trato en CRM.
- Ir al HUB resolviendo la conversación vinculada.
- Historial de notas en modal.
- Badge de vencido.
- Responsive móvil: las filas pasan a cards verticales.

## Reads
- Si Mi Estado ya cargó el fallback exacto del owner, los bloques reutilizan el cache durante 60 s (0 reads adicionales por bloque).
- Con índices disponibles, cada bloque consulta solo la página necesaria (25 registros).
- No se usa collection.get() global sin owner ni scans de toda la base.
