# MRAPI HUB v1.5.30 - Gateway bridge

Agrega compatibilidad inicial con MRAPI Gateway / Meta Cloud API sin quitar Twilio.

Variables nuevas:
- MRAPI_GATEWAY_URL
- MRAPI_GATEWAY_API_KEY  (debe coincidir con INTERNAL_API_KEY del Gateway)
- MRAPI_GATEWAY_SECRET   (debe coincidir con Secret Hub configurado en el tenant del Gateway)
- MRAPI_GATEWAY_TENANT_ID

Flujo soportado en esta versión:
- Entrada texto: Meta -> Gateway -> Hub -> Bandeja
- Salida texto: Hub -> Gateway -> Meta -> WhatsApp
- Estados básicos: Gateway -> Hub
- Twilio sigue funcionando para las líneas existentes

Todavía no se habilitan por Gateway desde Hub:
- archivos/media salientes
- templates Meta desde la UI del Hub
