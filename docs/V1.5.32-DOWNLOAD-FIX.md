# v1.5.32 - Descarga de media autenticada

Corrige el botón Descargar foto/audio/documento en Bandeja.

Problema:
- El Hub usa token Bearer guardado en localStorage.
- El link directo <a href=.../download> abría otra navegación sin enviar Authorization.
- El endpoint respondía: {"ok":false,"error":"Sesión requerida"}.

Solución:
- La descarga ahora se hace con fetch() enviando Authorization: Bearer <sesión>.
- El navegador recibe el Blob y dispara la descarga local.
- No cambia dónde se almacenan los archivos: siguen guardándose en MRAPI_FILES_BUCKET del Hub.
- Gateway continúa sin almacenamiento permanente de media.
