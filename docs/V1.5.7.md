# MR API HUB v1.5.7

## Desk SSO

HUB calls `POST /api/inbox/desk/sso` with the active MR API session. The response URL is `${MRAPI_DESK_BASE_URL}/auth/crm?token=...`. The token contains user id, email, name, role, tenant id, issued/expiry timestamps and a nonce, signed with HMAC-SHA256.

Required when Desk is enabled:

- `MRAPI_DESK_BASE_URL`
- `DESK_SSO_SECRET` — exact same value in HUB and Desk
- optional `DESK_SSO_TTL_SECONDS=60`

## Multi-line customers

On the first inbound message for a newly-created `(customer,line)` conversation, HUB performs one bounded lookup (max 20 conversations for that `waFrom`). When two or more distinct receiving lines exist it materializes:

- `linkedLineIds`
- `duplicateConversationIds`
- `multiLineDetected`
- `multiLineCount`

Existing historical conversations are detected/repaired once when opened. The list receives a warning badge and the chat receives a warning banner.
